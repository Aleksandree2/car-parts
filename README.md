# AutoZona.ge 🔧

მარტივი სტატიკური საიტი ავტონაწილების კატალოგისთვის — სურათებით,
კატეგორიების ფილტრით და ძებნით. არანაირი ბილდი, ფრეიმვორკი ან სერვერი.

## თემა

საიტი **მუქია ნაგულისხმევად** — სისტემის არჩევანს არ მიჰყვება, ყველა
სტუმარი მუქს ხედავს. ზედა კუთხის ღილაკით (☀ / ☾) შეიძლება ნათელზე
გადართვა და არჩევანი ბრაუზერში შეინახება.

ფერები მხოლოდ CSS ტოკენებითაა `styles.css`-ში: `:root` — მუქი
(ნაგულისხმევი), `:root[data-theme="light"]` — ნათელი. ახალი ფერის
დამატებისას ორივე ბლოკში ჩაწერე, თორემ ერთ თემაზე გაუჩინარდება.

## გაშვება

უბრალოდ გახსენი `index.html` ბრაუზერში.

## ბექოფისი (admin.html)

გახსენი `admin.html` — იქიდან იმართება ყველაფერი, კოდის შეხების გარეშე:

- **საიტი** — სათაური და ქვესათაური
- **სლაიდერი** — ბანერები მთავარ გვერდზე, კატეგორიების ზემოთ
- **კატეგორიები** — დამატება, გადარქმევა, თანმიმდევრობა, ფოტო, წაშლა
- **ნაწილები** — დამატება, რედაქტირება, ფოტოები, ფასი, ფასდაკლება, აღწერა, წაშლა

ფასდაკლებისთვის შეავსე „ფასდაკლებული ფასი" — ბარათზე ძველი ფასი
გადახაზული გამოჩნდება და პროცენტიც დაითვლება. ცარიელი ველი ნიშნავს,
რომ ფასდაკლება არ არის.

ცვლილებები ინახება ბრაუზერში. როცა მორჩები, დააჭირე
**„შენახვა საიტზე“** — იხილე ქვემოთ. (ან **„data.js“** → ჩამოტვირთვა/კოპირება,
თუ ხელით გინდა კომიტი.)

> **ყურადღება:** ბექოფისს პაროლი არ აქვს და საიტთან ერთად აიტვირთება.
> ის ვერაფერს შეცვლის სერვერზე (მხოლოდ ფაილს გენერირებს), მაგრამ თუ არ
> გინდა საჯაროდ ხელმისაწვდომი იყოს, არ ატვირთო `admin.html`, `admin.js`
> და `admin.css` — ლოკალურად მაინც იმუშავებს.

### ფოტოები: ორი გზა

| გზა | როგორ | როდის |
|-----|-------|-------|
| **ატვირთვა** | „ფოტოს ატვირთვა" ბექოფისში | სწრაფი — ფოტო ჩაჯდება `data.js`-ში (ავტომატურად პატარავდება 900px-მდე) |
| **ფაილი** | ჩააგდე `images/`-ში, მიუთითე `images/name.jpg` | სჯობს, როცა ბევრი ფოტოა — `data.js` პატარა რჩება |

ბევრი ატვირთული ფოტო `data.js`-ს ბერავს. თუ ზომა 1–2 MB-ს გადააჭარბებს,
გადადი `images/`-ზე.

## შენახვა პირდაპირ საიტზე

ბექოფისში „**შენახვა საიტზე**“ ცვლილებებს პირდაპირ რეპოზიტორიაში წერს —
ჩამოტვირთვა და ხელით კომიტი აღარ სჭირდება. GitHub Pages თავად გადაეწყობა
და საიტი ~1 წუთში განახლდება.

### ერთჯერადი მომზადება

1. შექმენი [fine-grained token](https://github.com/settings/personal-access-tokens/new)
   - **Repository access** → *Only select repositories* → `car-parts`
   - **Repository permissions** → **Contents** → *Read and write*
   - **Expiration** — მიუთითე ვადა (მაგ. 90 დღე)
2. ბექოფისში გახსენი ჩანართი **კავშირი**, ჩასვი თოკენი
3. დააჭირე **კავშირის შემოწმება** → უნდა დაწეროს `✓ კავშირი მუშაობს`

### თოკენის შესახებ

თოკენი ინახება **მხოლოდ შენს ბრაუზერში** (localStorage). ის არ ხვდება
რეპოზიტორიაში და არსად არ იგზავნება GitHub-ის გარდა. მაგრამ:

- საერთო ან უცხო კომპიუტერზე ნუ შეინახავ — დამთავრებისას „თოკენის წაშლა“
- მიეცი ვადა, რომ სამუდამოდ არ დარჩეს
- მხოლოდ **Contents** უფლება მიეცი, სხვა არაფერი
- ნებისმიერ დროს გააუქმებ [GitHub-ის პარამეტრებში](https://github.com/settings/personal-access-tokens)

### რა ხდება შენახვისას

ერთ კომიტში იგზავნება ყველაფერი, რომ Pages ერთხელ გადაეწყოს:

- ატვირთული ფოტოები ინახება `images/`-ში **ნამდვილ ფაილებად**
  (და არა base64-ად `data.js`-ში)
- `data.js` ინახავს მხოლოდ ბილიკებს, ამიტომ პატარა რჩება

თუ შენახვა ვერ მოხერხდა, ცვლილებები ბრაუზერში რჩება — არაფერი იკარგება.
სათადარიგო გზად „**data.js**“ ღილაკი ისევ ადგილზეა.

## ახალი ნაწილის დამატება

1. ჩააგდე სურათი `images/` საქაღალდეში (მაგ. `images/radiator.jpg`).
2. გახსენი `data.js` და დაამატე ახალი ბლოკი `PARTS` სიაში:

```js
{
  name: "რადიატორი",
  category: "dzrava",
  price: 240,
  images: ["images/radiator-1.jpg", "images/radiator-2.jpg"],
  description: "ალუმინის რადიატორი, კონდიციონერიანი ვერსიისთვის",
},
```

პირველი ფოტო მთავარია — ის ჩანს ბარათზე. ძველი `image: "..."` ველიც
მუშაობს, ოღონდ ბექოფისიდან შენახვისას `images`-ად გადაკეთდება.

თუ სურათი არ არსებობს, ბარათზე ავტომატურად გამოჩნდება placeholder.

## ახალი კატეგორიის დამატება

`data.js`-ში, `CATEGORIES` სიაში:

```js
{ id: "konditsioneri", name: "კონდიციონერი" },
```

`id` უნდა ემთხვეოდეს იმას, რასაც ნაწილის `category` ველში წერ.

## ქეში

`index.html`-სა და `admin.html`-ში CSS/JS ფაილებს ვერსია აქვს მიწერილი
(`app.js?v=9`). კოდის შეცვლისას **ყველგან გაზარდე ეს ციფრი** — თორემ
ბრაუზერები ძველ ფაილს გააგრძელებენ და ცვლილება არ გამოჩნდება.

`data.js`-ს ვერსია განზრახ არ აქვს: მას ბექოფისი წერს და ფიქსირებული
ვერსია ახალ ფოტოებს დამალავდა. GitHub Pages მას ~10 წუთი ინახავს.

## Excel-იდან მასობრივი დამატება

ნაწილების ჩანართში **Excel-იდან** ღილაკი კითხულობს `.xlsx`-სა და `.csv`-ს.

პირველი სტრიქონი სვეტების სახელებია (ქართულიც და ინგლისურიც მუშაობს):

| სვეტი | სავალდებულო | შენიშვნა |
|-------|-------------|----------|
| დასახელება / name | კი | |
| კატეგორია / category | კი | სახელითაც და id-თაც იძებნება |
| ფასი / price | კი | |
| ფასდაკლება / sale | არა | ფასზე ნაკლები უნდა იყოს |
| აღწერა / description | არა | |
| ფოტოები / images | არა | რამდენიმე — მძიმით გამოყოფილი ბილიკები |

დამატებამდე ჩანს ცხრილი, სადაც ყოველი სტრიქონის სტატუსი წერია.
პრობლემური სტრიქონები გამოიტოვება, დანარჩენები დაემატება. თუ ფაილში
უცნობი კატეგორიაა, შეგიძლია ავტომატურად შექმნა.

**ნიმუშის ჩამოტვირთვა** იძლევა მზა CSV-ს სწორი სვეტებით.

### ფოტოები იმპორტისას

ფოტოების სვეტში სამნაირი მნიშვნელობა მუშაობს:

| რას წერ | რა ხდება |
|---------|----------|
| `disk1.jpg` | ეძებს იმავე სახელის ფაილს, რომელიც „ფოტოების არჩევა"-ში აირჩიე |
| `images/disk1.jpg` | უკვე რეპოზიტორიაში არსებული ფაილი |
| `https://…` | გარე ბმული |

ანუ: ცხრილში ჩაწერე ფაილების სახელები, შემდეგ დააჭირე **ფოტოების
არჩევა** და მონიშნე იგივე ფაილები — სახელით დაემთხვევა (დიდ-პატარა
ასოებს არ არჩევს). ფოტოები ავტომატურად პატარავდება და შენახვისას
`images/`-ში ჩაიწერება.

თუ რომელიმე ფოტო ვერ მოიძებნა, ნაწილი მაინც დაემატება — უბრალოდ ამ
ფოტოს გარეშე, და ცხრილში ყვითლად მოინიშნება.

დამატების შემდეგ არ დაგავიწყდეს **შენახვა საიტზე**.

## ორი ადამიანი ერთდროულად

შენახვა მთელ კატალოგს წერს, ამიტომ ორი ერთდროული რედაქტირება ერთმანეთს
გადააფარებდა. ამის თავიდან ასაცილებლად:

- თუ შენახვის შუაში სხვამ შეინახა და `data.js` არ შეცვლილა (მაგ. მხოლოდ
  ფოტო დაამატა), შენახვა ავტომატურად მეორდება
- თუ `data.js` შეიცვალა, შენახვა **ჩერდება** და გაფრთხილება ჩნდება —
  სხვისი ცვლილებები არ იშლება

გაფრთხილების შემთხვევაში: დააჭირე **data.js** და დააკოპირე შენი ვერსია,
შემდეგ **თავიდან ჩატვირთვა** და ხელახლა შეიტანე ცვლილებები.

ჩვევად აიღე: რედაქტირების დაწყებამდე დააჭირე **თავიდან ჩატვირთვა**.
