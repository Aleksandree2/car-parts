# ავტონაწილები 🔧

მარტივი სტატიკური საიტი ავტონაწილების კატალოგისთვის — სურათებით,
კატეგორიების ფილტრით და ძებნით. არანაირი ბილდი, ფრეიმვორკი ან სერვერი.

## გაშვება

უბრალოდ გახსენი `index.html` ბრაუზერში.

## ბექოფისი (admin.html)

გახსენი `admin.html` — იქიდან იმართება ყველაფერი, კოდის შეხების გარეშე:

- **საიტი** — სათაური და ქვესათაური
- **კატეგორიები** — დამატება, გადარქმევა, თანმიმდევრობა, ფოტო, წაშლა
- **ნაწილები** — დამატება, რედაქტირება, ფოტო, ფასი, აღწერა, წაშლა

ცვლილებები ინახება ბრაუზერში. როცა მორჩები, დააჭირე
**„data.js ჩამოტვირთვა"** → ჩამოტვირთე ან დააკოპირე ტექსტი →
ჩაანაცვლე პროექტში არსებული `data.js` → დაკომიტე.

> **ყურადღება:** ბექოფისს პაროლი არ აქვს და საიტთან ერთად აიტვირთება.
> ის ვერაფერს შეცვლის სერვერზე (მხოლოდ ფაილს გენერირებს), მაგრამ თუ არ
> გინდა საჯაროდ ხელმისაწვდომი იყოს, არ ატვირთო `admin.html`, `admin.js`
> და `admin.css` — ლოკალურად მაინც იმუშავებს.

### ფოტოები: ორი გზა

| გზა | როგორ | როდის |
|-----|-------|-------|
| **ატვირთვა** | „ფოტოს ატვირთვა" ბექოფისში | სწრაფი — ფოტო ჩაჯდება `data.js`-ში (ავტომატურად პატარავდება 900px-მდე) |
| **ფაილი** | ჩააგდე `images/`-ში, მიუთითე `images/name.jpg` | სჯობს, როცა ბევრი ფოტოა — `data.js` პატარა რჩება |

ბევრი ატვირთული ფოტო `data.js`-ს ბერავს. თუ ზომა 1–2 MB-ს გადააჭარბებს,
გადადი `images/`-ზე.

## ახალი ნაწილის დამატება

1. ჩააგდე სურათი `images/` საქაღალდეში (მაგ. `images/radiator.jpg`).
2. გახსენი `data.js` და დაამატე ახალი ბლოკი `PARTS` სიაში:

```js
{
  name: "რადიატორი",
  category: "dzrava",
  price: 240,
  image: "images/radiator.jpg",
  description: "ალუმინის რადიატორი, კონდიციონერიანი ვერსიისთვის",
},
```

თუ სურათი არ არსებობს, ბარათზე ავტომატურად გამოჩნდება placeholder.

## ახალი კატეგორიის დამატება

`data.js`-ში, `CATEGORIES` სიაში:

```js
{ id: "konditsioneri", name: "კონდიციონერი" },
```

`id` უნდა ემთხვეოდეს იმას, რასაც ნაწილის `category` ველში წერ.
