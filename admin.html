ეს ტექსტი ჩანს Google-ის შედეგებში და სოციალურ ქსელებში გაზიარებისას. კარგია, თუ ის სიტყვებია, რომლითაც შენს საქონელს ეძებენ.

სლაიდერი

ბანერები მთავარ გვერდზე, კატეგორიების ზემოთ. თუ ერთიც არ არის, სლაიდერი საერთოდ არ ჩანს.

კატეგორიები

ფოტო არასავალდებულოა — თუ დაამატებ, ფილტრის ღილაკზე გამოჩნდება.

ნაწილები

კავშირი GitHub-თან

ამ პარამეტრებით „შენახვა საიტზე“ ცვლილებებს პირდაპირ რეპოზიტორიაში ჩაწერს და საიტი ერთ წუთში განახლდება.

თოკენი მხოლოდ შენს ბრაუზერში ინახება. ის არასდროს ხვდება რეპოზიტორიაში და არსად არ იგზავნება GitHub-ის გარდა. საერთო ან უცხო კომპიუტერზე ნუ შეინახავ — დამთავრებისას დააჭირე „თოკენის წაშლა“. ნებისმიერ დროს შეგიძლია გააუქმო GitHub-ის პარამეტრებში.
როგორ შევქმნა თოკენი
  1. გახსენი Fine-grained token-ის შექმნის გვერდი
  2. Repository access → Only select repositories → აირჩიე car-parts
  3. Repository permissions → Contents → Read and write
  4. Expiration — მიუთითე ვადა (მაგ. 90 დღე), რომ სამუდამოდ არ დარჩეს
  5. დააგენერირე, დააკოპირე და ჩასვი ზემოთ

სხვა უფლება არ სჭირდება — მხოლოდ Contents.

ნაწილის რედაქტირება

პირველი ფოტო მთავარია — სწორედ ის ჩანს ბარათზე. ერთდროულად რამდენიმეს არჩევაც შეიძლება.

ახალი data.js

ჩამოტვირთე ან დააკოპირე და ჩაანაცვლე პროექტში არსებული data.js, შემდეგ დაკომიტე.

ნაწილების იმპორტი

Excel (.xlsx) ან CSV ფაილი, სადაც პირველი სტრიქონი სვეტების სახელებია: დასახელება, კატეგორია, ფასი, ფასდაკლება, აღწერა, ფოტოები. სავალდებულოა მხოლოდ დასახელება, კატეგორია და ფასი.

ფოტოების სვეტში ჩაწერე ფაილების სახელები (მაგ. disk1.jpg, disk2.jpg), შემდეგ აირჩიე იგივე ფაილები — სახელით დაემთხვევა. მზა ბილიკი (images/…) და ბმულიც მუშაობს.

ფაილში კატეგორიის სვეტი არ არის — აირჩიე, რომელ კატეგორიაში მოხვდეს ეს ნაწილები.
